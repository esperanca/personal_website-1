# Mídias da apresentação

Coloque aqui os arquivos referenciados no `slides.md` (caminhos começam com `/media/`):

- Vídeos: `.mp4` (H.264 + AAC é o formato mais compatível). Para vídeos verticais, use 1080×1920 (9:16).
- Pôsteres: imagens exibidas antes do play (`poster`). Use proporção igual à do vídeo.
- Imagens: JPG, PNG, WebP ou SVG.

Os arquivos `poster-*.svg` e `imagem-exemplo.svg` são apenas placeholders da apresentação demonstrativa; substitua-os pelos seus.
